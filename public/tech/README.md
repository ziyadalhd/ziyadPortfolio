# Technology logos

- SVG logos: [Devicon](https://devicon.dev/), downloaded from `devicons/devicon` (`icons/<name>/<name>-original.svg`). Devicon's MIT license is included in `LICENSE-devicon.txt`. Logos identify their respective technologies.
- SwiftUI: [Apple Developer](https://developer.apple.com/swiftui/), original asset at `https://developer.apple.com/assets/elements/icons/swiftui/swiftui-96x96_2x.png`.

Only technologies with an identifiable brand asset appear as logos. Architecture concepts and techniques remain documented in the project details.
