# Original project assets

## Irtiwa

Imported from the local H2OCalm application project:

- `irtiwa/logo.svg`: `Assets.xcassets/IrtiwaCupMark.imageset/IrtiwaCupMark.svg`.
- `irtiwa/icon.png`: original `AppIcon.appiconset/AppIcon.png`.
- `irtiwa/*-{ar,en}.png`: demo-data captures in `docs/release/screenshots/6.9`, dated 23 October 2026. These are local captures, not evidence of an App Store release.
- `src/data/irtiwa-artwork.ts`: exact original bottle contours exported from `IrtiwaBottleArtwork.swift`. The animated grooves and reflection coordinates come from `IrtiwaBottle.swift`.
- Cup contours and reflection pixels follow `IrtiwaPixelArtwork.swift` and `IrtiwaCupDetails.swift`.

## Bayn

`bayn-logo.svg` is the owner-approved `public/brand/club-logo-on-green.svg` from the Bayn repository. Its original paths, color and aspect ratio are retained. The artwork uses an ivory backing for contrast in both portfolio themes.

Wasl and Wedding Greetings now use original branding or actual application captures. Their source details are recorded in the respective asset folders.

## Wasl update

Wasl now uses the owner's original logo files and app regions extracted from the graduation report. See `wasl/README.md`; its old typographic placeholder has been replaced.

## Wedding Greetings

`wedding-greetings/` contains actual local UI captures with demo text, from the owner's application. See its README for the isolated capture setup and pending venue photographs.
